# 板型与量能：什么板能打、什么板不能打

SKILL.md 第四节 4.5 的展开。讲三件事：**① 板型清单（哪种形态、能不能打）② 一进二的量能定档（本机实测校准）③ 黑名单**。

## 一、口径先定死

- **缩量板 / 放量板是相对量，不是绝对值**。缩量板＝当日成交量显著低于基数却封住；换手板（放量板）＝当日量接近或超过基数。【二手：理想论坛「涨停形式科普」】
- **基数按场景选，混用会得出相反结论**：
  1. **昨日成交额** —— 判一进二（二板上板那一刻的当日量能 vs 首板）。
  2. **左侧 60 日顶量** —— 判突破板、多重顶；首板是缩量板时**必须**用它。
  3. **近 5–20 日均量** —— 判「是不是爆量」「是不是缩量过度」。
- **一字板 / 前一日缩量板不能当基数**：一字板当日成交被涨停价限制，倍数天然失真（与第四节「量能基数不能取前一日一字板」同一条）。
- **一字板不是板型判断问题，是可执行性问题**：`low >= up_limit - 0.005` 就是全天没在涨停价下方成交过 = 打板买不到。凡是「缩量板很健康」的结论，先过这道门。

## 二、板型清单（13 种）与可打性

【原文：酋长《股票涨停板形态及具体打板方法解读》，华尔街见闻转载，2021-02-25】

| 板型 | 定义 | 能量/筹码含义 | 能不能打 |
|---|---|---|---|
| 一字板 | 涨停价开盘、全天不开板 | 极度看好、无换手、无成交 | 买不到就观望，**不建议天天排队**（排队只增强封单）；连续一字后放量破板不回封 → 不低吸、放弃 |
| 实体板（力度板） | 低/高开后拉到涨停，日内有价格运动 | 换手充分、最真实 | 可打，但**必须已上板再打**，不半路追、不触板抢 |
| 重力板 | 上涨中后期顶住巨量抛压、频繁换手拉板 | 主力主动上涨，格局大 | 一般板客难把握，适合滚动/做 T |
| T 字板 | 一字开盘、盘中破板放量、回封收盘 | 不稳定的一字板 / 超强实体板 | **低位可打，高位危险**；相对前日合理缩量或适度放量较好，**超量巨量 T 字风险高** |
| 缩量板 | 相对基数明显缩量却封住 | 锁仓、惜筹；也可能是始终没换手 | 看左侧：**左侧放量 → 好**；左侧本来就缩量 → 危险信号 |
| 放量板/换手板 | 当日量接近或超过基数 | 分歧、抛压释放 | 看左侧：**左侧缩量 → 均匀放量好**；左侧已放量 → 再放量＝分歧加剧 |
| 烂板 | 盘中反复炸板、收盘封住 | 分歧大 | **主动分歧可做（低位、量能稳定）；被动分歧绝对不能接（高位＋爆天量）** |
| 秒板/一笔上板 | 分时一笔直线拉板 | 主力决心，但没换手 | 分时流畅一气呵成才敢打；「一步三回头」不打 |
| 突破板 | 突破平台/前高 | 老形态优质，现在常成骗炮板 | **真突破（有量、分时流畅）可打；异常天量 → 不打，等次日缩量涨停修复再打** |
| 加速板 | 已有涨幅后继续涨停 | 一致加速 | 位置决定性质；首次缩量加速不追 |
| 分歧板 | 盘中大分歧后回封 | 分歧转一致 | 可打，要能确认回封成立 |
| 确认板（确定板） | 首板之后那根再次涨停 | 对首板的确认 | **大牛股第一买点**（形态学版的「二板定龙头」） |
| 反包板 | 断板/放量阴线后重新涨停 | 洗盘 vs 出货的分界 | 首板易被闷杀，**反包二板才算确认**（同第四节买点 8） |

**报告里只用 6 个词**（13 种留给研究，不摆进个股点评）：一字板 / T 字板 / 换手板（放量板）/ 缩量板 / 烂板 / 反包板。不自造名词。

## 三、三个流派：板位 × 量能的标准（冲突必须摆明，不硬合并）

- **流派一 · 板学口径**：首板放量＝分歧启动，**二板放量＝分歧确认**，三板缩量＝一致加速。【二手：东方财富「板学知识普及」】→ 明确反对「二板缩量」。
- **流派二 · 一进二口径**：**首板放量 → 二板量能 1/2–2/3 为健康**；首板未放量 → 二板需达左侧压力区顶量 2/3；多重顶 → 前述健康量 ×1.5。量能不足＝抛压没释放，量能异常放量＝抛压超预期，**两头都不健康**。【原文：淘股吧《万战寻道讲一进二的填充·五大要素之量能》，2022-10-16 直播整理】
- **流派三 · 交替口径**：左侧放量则今日宜缩量，左侧缩量则今日宜均匀放量，左侧平量则今日放量或平量。最优能量演进＝「逐个放量启动 → 逐个缩量压缩 → 放量冲顶」，其次「缩量放量交替」；「逐个缩量」第三，「持续缩量一字」最差（一波到头且参与不了）。【原文：酋长，同上】

**三家不冲突的公共部分（可当原理写）**：

> 量能要**放缩交替**，不能一路缩、也不能一路爆。一路缩＝没换手、开板即抛压；一路爆＝分歧加剧、接力资金被吃。
> 判某天的板好不好，看**它左侧那根的量**，而不是孤立看当天多少量。

**冲突部分（二板该缩还是该放）用本机实测解决，见第四节。**

## 四、二板量能定档（本机实测，20260803–20261029）

口径：二板量能比 = 二板上板日成交额 / 首板成交额；打板收益只在「可打样本」（触板 且 非一字）里算，买价＝涨停价，封住 → T+2 收盘卖、炸板 → T+1 收盘卖。样本：首板 3458 笔（主板 3226 / 创业板 232）、可打 863 笔、57 个交易日。环境：上证 -4.6%、创业板指 -26.9%。

```
档位       可打   炸板率   收盘卖均值   8月/9月/10月（炸板率·收益）
<2/3        53    0.0%     +4.1%      0%·+6.1% / 0%·+2.2% / 0%·+4.1%
2/3-1       59    1.7%     +3.3%      4%·+3.7% / 0%·+2.1% / 0%·+4.4%
1-1.5      162   16.0%     +0.4%      9%·+1.4% / 13%·+0.7% / 30%·-1.6%
>1.5       589   44.5%     -2.5%      41%·-1.2% / 50%·-2.8% / 42%·-4.2%
全样本      863   33.5%     -1.17%
```

**定档结论**：

- **≤ 首板 1.0 倍 → 打**（炸板 ≤1.7%、+3.3%~+4.1%）。但先判可执行性：这一档约**七成是一字板**（<1/3 档一字率 68%、1/3–1/2 档 53%、1/2–2/3 档 28%），买不进就没有这笔交易，剩下的两成才是利润来源。
- **1–1.5 倍 → 半仓**，只做板块龙头/情绪龙（炸板 16%、+0.4%）。
- **>1.5 倍 → 不打**（炸板 44.5%、-2.5%）。不是「必炸」（约 55% 封住），是**期望为负**。
- **首板缩量时用左侧 60 日顶量作基数**：二板量能 <1/2 顶量 → 炸板 3–4%、+2%~+4%；**>1 倍顶量 → 炸板 50.4%、-3.7%（139 笔，本区间最硬的坏信号）**。
- **首板自身放量与否不作筛选条件**：缩量<0.8 / 平量 / 放量1.2-2 / 2-3 / 爆量>3 五档，可打封板率 64.1%–67.4%（差 3pt）、收益 -0.9%~-1.8%（差 1pt），全在噪声里。唯一差别是触板率（缩量首板次日触板 55.7% vs 放量 24-26%），但其中 12.4% 是一字买不到。
- **陈小群「二板量 > 首板 1.2 倍」落在 1–1.5 档**（16% 炸板、+0.4%），本区间明显不如 ≤1 倍档——他那是「确认龙头后接力」，与一进二不是同一笔生意，两种口径不能混用。

**局限（引用这张表必须带）**：

- 全天量能 ≠ 上板那一刻的量能（封板后仍有成交），缩量档存在轻微「看结果」偏差；实盘要在上板瞬间用分时累计量估，回测只能给方向。
- 创业板 8–10 月只有 232 笔首板、可打 17 笔 → **结论是主板口径**。
- ≤1 倍档合计 112 笔、月度 11–28 笔，统计不厚，不是稳定 alpha。
- 区间内打板整体负期望（-1.17%），**分档的相对优势有效，绝对收益不能外推**。

重跑：`python3 scripts/calibrate_board_volume.py --start 20260801 --end 20261029`（逐日缓存 `~/.hermes/cache/limitpool/`，重复区间秒出）。

## 五、黑名单：不打 / 减半的板

1. **连续一字或缩量之后的第一次放量板** —— 首次真实换手，没有承接参照系（同第四节买点 3 的补充）。
2. **高位被动分歧烂板** —— 位置高（≥5 板）＋爆天量＋封不住，主力无力抵抗，绝对不能接。
3. **异常天量的突破板** —— 不打；等次日能否**缩量涨停**修复，缩量涨停＝确认可打，继续放量→继续观察。
4. **尾盘偷袭板**（14:30 后封）—— 资金套利或弱势表现，一进二成功率低。
5. **首板缩量秒板且左侧无换手平台** —— 没换手的一进二。
6. **二板量能 > 首板 1.5 倍** —— 炸板率 44.5%、期望 -2.5%（见第四节）。
7. **二板量能 > 左侧 60 日顶量（首板缩量场景）** —— 炸板率 50.4%。

第 1–3 条与 SKILL.md 第四节禁区同源，这里只是从**板型**角度重述，不重复展开；第 6–7 条是本机实测新增的量化禁区。

## 六、可算口径（Tushare）

| 指标 | 取法 | 备注 |
|---|---|---|
| 当日上板量能 | `daily.amount` | **单位千元** |
| 昨日基数 | 前一交易日 `daily.amount` | 停牌日没有行，要跳过 |
| 左侧顶量 | 前 20–60 日 `daily.amount` 最大值 | 突破板/多重顶/首板缩量场景 |
| 近期均量 | 近 5 / 20 日 `amount` 均值 | 判爆量 |
| 换手 | `daily_basic.turnover_rate_f` | **自由流通口径**，与死亡换手 65% 那条禁区一致 |
| 封板质量 | `limit_list_d.first_time` / `fd_amount` / `open_times` | 封单/成交 ≥8% |
| 可执行性 | `daily.low >= stk_limit.up_limit - 0.005` | 真＝一字板，打不进 |
| 竞价量 | `stk_auction_o` 无权限 → 新浪 09:31 首根 1min `amount` 代理 | 沿用例「首板战法」的坑 |

## 七、盘中落地：「今天打哪个」的五步

1. **先判环境能不能打（命中任一即空仓，不必再选票）**：昨涨停池今日涨幅中位为负 / 昨日首板晋级率 <30%（发酵线）/ 今天是定期报告截止前最后一个交易日（打板天然是隔夜单）。三条任一成立，「不打」就是答案，后面四步只用来写理由。
2. **候选池 = 昨日 U 池**：`limit_list_d(trade_date=昨, limit_type='U')`，取 `limit_times`（当日板数）/ `up_stat`（几天几板）/ `first_time` / `open_times` / `fd_amount` / `turnover_ratio`。`limit_times==1` 才是首板，否则是接力位，用的是别的尺子。
3. **一次 `ts.realtime_quote` 批量取数**（≤400–600 只/次，超限静默返回 None）：`PRICE` / `OPEN` / `HIGH` / `LOW` / `PRE_CLOSE` / `AMOUNT` / `B1_V`。涨停价按板块算：主板 `round(pre*1.1,2)`、创业板/科创板 `×1.2`。
   - 触板 = `HIGH >= 涨停价 - 0.005`；封住 = `PRICE >= 涨停价 - 0.005`；炸板 = 触板且未封住。
   - **一字 = `OPEN` 与 `LOW` 都贴在涨停价**。用 `HIGH` 判会把一字和秒板混成一类。
4. **量能必须折算成区间，不给单值**：分子用 `AMOUNT/1000`（元→千元）与 `daily.amount`（千元）同口径，分母用首板全天成交额。盘中只过了 X% 交易时长，而 A 股成交前重后轻，**同时报「线性 X%」与「典型 55%」两个折算值**（例：11:07 过了 40.4%，就报 36%~49%）。给单值等于假装知道全天量，且会被用户当承诺。
5. **按第四节定档下结论**：≤1 倍 → 可打，但先看一字率（这一档多半买不到）；1–1.5 → 半仓；>1.5 → 不打。**结论允许是「今天不打」，而且这是常态**——全样本打板期望 -1.17%，没有合格标的就是正解，不要为了凑一个名字降标准。

两条盘中话术纪律：

- **「最强的那只」和「能打的那只」不是同一只**：封单 3 亿、量能 36% 的往往正是买不进的一字板。它进观察表（等首次开板放量回封），不进候选。
- 盘中结论要在稿里留一句「收盘后可用 18:00 完整池子复核」——盘中量能是折算值，收盘可能改档。
